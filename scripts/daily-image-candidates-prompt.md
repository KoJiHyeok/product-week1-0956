# 제목 학원 일일 이미지 후보 생성

매일 실행할 때 아래 절차를 정확히 따른다.

1. `/Users/kojh/dev/jemokhakwon/product-week1-0956`의 현재 갤러리 이미지와 메타데이터를 확인한다.
2. `content/image-preferences.json`의 승인·탈락 기록과 선호 강도를 읽는다. `preference`는 후보 구성에 가중치로 반영하되 절대 규칙처럼 모든 후보에 강제하지 않는다.
3. 최근 3회분 `output/image-candidates/YYYY-MM-DD/`도 확인한다. 갤러리에 없는 탈락작까지 포함해 소재, 행동, 장소, 구도를 반복하지 않는다.
4. 이미지 생성 전에 제목 짓기용 사진 아이디어를 최소 12개 만든다. 각 아이디어를 아래 기준으로 0~2점씩 평가하고 합계 6점 이상인 아이디어만 남긴다.
   - **행동의 명확성:** `있다`, `놓여 있다`가 아니라 목적이 드러나는 동사로 설명되는가
   - **사진의 자연스러움:** 사람이 소품을 일부러 배치한 광고 사진보다 우연히 포착한 생활 사진처럼 보이는가
   - **제목 확장성:** 서로 다른 해석의 제목을 즉석에서 3개 이상 만들 수 있는가
   - **새로움:** 기존 갤러리와 최근 탈락작의 소재·행동·구도 문법을 반복하지 않는가
5. 통과 아이디어 중 서사 구조가 서로 다른 4개를 고른다. 네 후보는 각각 `관계형`, `사건·흔적형`, `사회적 행동형`, `새로운 방향 탐색형`으로 구성한다. 네 장 모두 단독 사물 중심 구도나 같은 의인화 공식으로 만들지 않는다.
6. `$imagegen`을 사용해 후보마다 별도 호출로 이미지 4장을 생성한다. 한 번의 다중 변형 요청을 사용하지 않는다.
7. 생성 규칙:
   - `photorealistic-natural` 유형의 가로형 사진
   - 한눈에 이해되는 행동·목적과 가벼운 반전
   - 중심 대상은 1~2개
   - 지나치게 깨끗한 스튜디오·제품 사진, 정중앙에 고립된 사물, 단순히 엉뚱한 장소에 물건만 놓은 장면 제외
   - 자연광, 생활 흔적, 주변 맥락, 약간 불완전한 프레이밍을 활용해 실제 스냅사진 같은 질감 유지
   - 브랜드 로고, 글자, 워터마크, 유명인, 저작권 캐릭터 금지
   - 혐오·폭력·선정적 내용 및 식별 가능한 실제 인물 금지
8. 생성 결과를 같은 평가 기준으로 다시 검사한다. 6점 미만이거나 제목 3개가 나오지 않는 후보는 전송하지 말고 해당 후보만 한 번 다시 생성한다. 재생성 후에도 기준 미달이면 파일은 보존하고 실패 원인을 보고한다.
9. 통과한 결과를 `output/image-candidates/YYYY-MM-DD/`에 `candidate-1`부터 `candidate-4`까지 저장하고, 네 이미지가 모두 정상적으로 열리며 서로 다른 장면인지 확인한다.
10. 다음 명령으로 Discord 채널에 후보를 전송한다.

   ```bash
   node scripts/send-discord-image-candidates.mjs \
     output/image-candidates/YYYY-MM-DD/candidate-1.png \
     output/image-candidates/YYYY-MM-DD/candidate-2.png \
     output/image-candidates/YYYY-MM-DD/candidate-3.png \
     output/image-candidates/YYYY-MM-DD/candidate-4.png
   ```

11. 후보 이미지를 사이트 갤러리에 추가하거나 커밋·푸시·배포하지 않는다. 사용자의 승인을 기다린다.
12. 전송에 실패하면 이미지 파일은 보존하고 오류 원인만 보고한다. Webhook URL이나 다른 비밀값은 출력하지 않는다.
